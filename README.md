# UIdesign

A Next.js recreation of the interactive Holo card pack page at https://holo.yashb.xyz/.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000/.

## Checks

```bash
npm run check
```

The page includes the pack-opening interaction, drag-to-tear behavior, card reveal sequence, sound toggle, replay button, responsive layout, and reduced-motion handling.
